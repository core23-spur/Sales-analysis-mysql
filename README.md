Учебный проект по анализу продаж интернет-магазина с помощью MySQL.

## 🎯 Цель проекта
Отработать навыки SQL для позиции бизнес-аналитика: 
сложные JOIN, оконные функции, агрегации, витрины данных.

## 📋 Бизнес-задачи
1. Посчитать выручку по месяцам и категориям товаров.
2. Найти топ-10 клиентов по сумме покупок.
3. Рассчитать средний чек и его динамику.
4. Определить товары-лидеры и аутсайдеры.
5. Построить воронку продаж.

## 📊 Данные
Источник: [Northwind Database (MySQL)](https://github.com/dalers/mywind)
Датасет содержит данные вымышленной компании Northwind Traders: 
клиенты, заказы, товары, сотрудники, поставщики, склад.

Таблицы:
- `customers` — клиенты компании
- `orders` — заказы
- `order_details` — позиции заказов
- `products` — товары
- `categories` — категории товаров (в поле `category` таблицы products)
- `employees` — сотрудники
- `suppliers` — поставщики
- `shippers` — службы доставки
- `invoices` — счета
- `inventory_transactions` — движения по складу

## 🗂 Структура репозитория
- `/data` — исходные данные
- `/sql` — SQL-скрипты (создание таблиц, аналитика)
- `/dashboards` — скриншоты графиков и дашбордов

## 🛠 Инструменты
MySQL, MySQL Workbench.
