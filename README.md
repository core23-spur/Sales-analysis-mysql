Учебный проект по анализу продаж интернет-магазина с помощью MySQL.

## 🎯 Цель проекта
Отработать навыки SQL для позиции бизнес-аналитика: 
сложные JOIN, оконные функции, агрегации, витрины данных.

## 📋 Бизнес-задачи
1. Посчитать выручку по месяцам и категориям товаров.
2. Найти топ-10 клиентов по сумме покупок.
3. Рассчитать средний чек и его динамику.
4. Определить товары-лидеры и аутсайдеры.
5. Построить воронку продаж.

## 📊 Данные
Источник: [Northwind Database (MySQL)](https://github.com/dalers/mywind)
Датасет содержит данные вымышленной компании Northwind Traders: 
клиенты, заказы, товары, сотрудники, поставщики, склад.

Таблицы:
- `customers` — клиенты компании

- `shippers` — службы доставки

- `inventory_transactions` — движения по складу

## 📈 Анализ данных

### Запрос 1: Выручка по месяцам

**Бизнес-задача:** понять динамику выручки по месяцам, выявить пики и провалы.

**SQL-запрос:**
```sql
SELECT
    DATE_FORMAT(orders.order_date, '%Y-%m') AS order_month,
    ROUND(SUM(order_details.quantity * order_details.unit_price), 2) AS revenue
FROM orders
JOIN order_details ON orders.id = order_details.order_id
GROUP BY order_month
ORDER BY order_month;
```

**Результат:**

| Месяц | Выручка |
|---|---|
| 2006-01 | 3 836.00 |
| 2006-02 | 2 241.50 |
| 2006-03 | 32 609.25 |
| 2006-04 | 19 355.25 |
| 2006-05 | 1 788.50 |
| 2006-06 | 8 306.50 |

**Промежуточный анализ:** формальный пик — март (32 609), но количество заказов в марте — всего 8, а в апреле — 17. Значит, высокая выручка марта объясняется не количеством сделок, а двумя крупными заказами (на 13 000+ каждый).

**Вывод:**
Выручка за январь–июнь 2006 года крайне нестабильна. Формальный пик пришёлся на март (32 609 руб.), минимум — на май (1 788 руб.). Разница между максимумом и минимумом — 18 раз.

Однако детальный анализ показал, что в марте было всего 8 заказов, из которых 2 — крупные (на 13 000+ каждый). В апреле, наоборот, было 17 заказов — в 2 раза больше, чем в марте, но без крупных сделок. Это говорит о двух вещах:
1. **Бизнес зависит от разовых крупных клиентов** — если такие заказы не повторятся, выручка резко падает.
2. **Реальный рост активности был в апреле** — там больше клиентов, но средний чек ниже.

Слабые месяцы (январь, февраль, май) держатся на уровне 1 800–3 800 руб. — это базовый поток заказов, который требует роста.

**Рекомендации:**
- Проанализировать, кто именно сделал крупные заказы в марте и есть ли шанс на повторные продажи.
- Изучить причины провала в мае — сезонность, отсутствие маркетинга или уход клиентов.
