# Данные

В проекте используется датасет **Northwind** (MySQL-версия).

Источник: https://github.com/dalers/mywind

## Файлы:
- `northwind.sql` — структура базы (в папке `sql/`)
- `northwind-data.sql` — данные (в папке `sql/`)

## Описание датасета:
Вымышленная компания Northwind Traders. В базе 14 таблиц: клиенты, 
заказы, товары, сотрудники, поставщики, складские операции.
Период данных: январь–июнь 2006 года.
