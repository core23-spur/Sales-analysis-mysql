# SQL-скрипты

Здесь хранятся все SQL-скрипты проекта: создание базы, загрузка данных 
и аналитические запросы.

## Файлы

| Файл | Назначение |
|---|---|
| `northwind.sql` | Структура базы данных (CREATE TABLE) |
| `northwind-data.sql` | Наполнение базы данными (INSERT INTO) |
| `01_revenue_by_month.sql` | Аналитический запрос: выручка по месяцам |

## Как запустить

1. Открой MySQL Workbench.
2. Выполни `northwind.sql` — создастся база `northwind` с таблицами.
3. Выполни `northwind-data.sql` — загрузятся данные.
4. Открывай аналитические скрипты (`01_...`, `02_...` и т.д.) и выполняй их.

## Соглашение об именах

Аналитические запросы нумеруются по порядку:
- `01_...` — первый запрос
- `02_...` — второй
- и так далее

Это позволяет видеть порядок анализа и легко добавлять новые запросы.
