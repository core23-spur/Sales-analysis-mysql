# SQL-скрипты

Здесь хранятся все SQL-скрипты проекта: структура базы, данные 
и аналитические запросы.

## Структура папки

| Файл | Назначение |
|---|---|
| `northwind.sql` | Создание структуры базы (таблицы, связи) |
| `northwind-data.sql` | Наполнение базы данными (INSERT) |
| `01_revenue_by_month.sql` | Аналитический запрос: выручка по месяцам |

## Как использовать

1. Выполните `northwind.sql` — создастся база `northwind` с таблицами.
2. Выполните `northwind-data.sql` — загрузятся данные.
3. Выполняйте аналитические запросы по одному — по мере изучения.

## Логика именования

Аналитические запросы нумеруются по порядку: `01_...`, `02_...`, `03_...`. 
Это помогает отслеживать последовательность анализа.
